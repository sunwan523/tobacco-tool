# 卷烟订单分析工具

这是一个基于 Streamlit 的本地项目，当前版本支持：

1. 行情价格本地库
2. 行情价格宽松查询
3. 订单盈亏分析
4. 订单与下一档位最高最贵满订差异
5. 本期档位最高满订汇总
6. 各档位按条数订满的最贵/利润优先对比汇总
7. 档位差异烟对比
8. 三十档最高利润订购推荐
9. 库存估值与盈亏
10. 库存缺失行情价格补录，并写回行情价格库

## 当前业务口径

- 订单分析、本期满订、档位差异烟，需要上传订单明细和订货量/投放表
- 行情价格保存在本地 `data/market_price_db.csv`
- 每次上传新的行情价格表，会覆盖价格库中同商品的旧找货价格
- 行情价格查询支持：
  - 商品名称部分文字
  - 商品名称拼音首字母
  - 拼音首字母的一部分
  - 条码、盒码
  - 条码/盒码超过 4 位的部分匹配
- `二次自选` 整段完全忽略，不参与任何订购、满订和推荐
- `按档位投放` 视为非价位段，按该档位可订量全量计入
- `订单与下一档位最高最贵满订差异` 的“下一档位”按降档比较：
  - 三十档订单对比二十九档
  - 二十九档订单对比二十八档
  - 以此类推
- “最高最贵满订”按批发价从高到低填满各价位段总量上限
- “利润优先满订”按单条毛利从高到低填满各价位段总量上限
- “三十档最高利润订购推荐”要求：
  - 总条数高于二十九档最高最贵满订
  - 总金额高于二十九档最高最贵满订
  - 在此基础上尽量让总利润最高
- 库存模块使用独立库存表，不再沿用订单量
- 如果库存商品存在正库存但没有行情价，会在页面中列出并允许补录，补录后写回本地价格库

## 安装依赖

```powershell
cd D:\codex\tobacco-tool
pip install -r requirements.txt
```

## 运行

```powershell
cd D:\codex\tobacco-tool
streamlit run streamlit_app.py
```

## 主要文件

- `D:\codex\tobacco-tool\streamlit_app.py`：主页面
- `D:\codex\tobacco-tool\tobacco_core\analysis.py`：解析和计算规则
- `D:\codex\tobacco-tool\tobacco_core\price_store.py`：行情价格库存储与宽松查询
