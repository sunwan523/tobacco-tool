# 卷烟订货测算工具

现在默认使用 Python + Streamlit 版本，适合继续扩展业务规则。

## 当前能力

1. 导入基础价格表、订单明细表
2. 按档位和分段规则测算满档最低金额、最高金额、实际订单差距
3. 支持直接修改指导零售价
4. 预留行情价字段，后续补齐后会自动参与最优组合和盈亏测算
5. 对订单做毛利分析
6. 可一次导入多份历史订单，按指定时间段汇总条数和金额

## 运行方式

1. 在 PowerShell 里进入项目目录：`D:\codex\tobacco-tool`
2. 运行：`.\run_app.ps1`
3. 浏览器会自动打开本地页面

也可以直接运行：

```powershell
python -m streamlit run D:\codex\tobacco-tool\streamlit_app.py
```

## 当前字段识别

价格表优先识别：

- 商品 / 商品名称
- 批发价 / 批发价格
- 建议零售价 / 零售价

订单表优先识别：

- 商品 / 商品名称
- 建议零售价 / 零售价
- 批发价 / 批发价格
- 需求量 / 可订量
- 订单量
- 金额

## 当前口径

- 分段按指导零售价划分
- 测算售价优先取行情价，没有行情价时取指导零售价
- 最优订货组合按单条毛利最大化推荐
- 可订量优先取需求量，没有则回落到订单量
- 历史汇总按订单日期筛选，适合季度评档统计

## 目录说明

- `streamlit_app.py`：界面入口
- `tobacco_core/io_utils.py`：Excel 读取与字段识别
- `tobacco_core/logic.py`：合并、测算、优化、盈亏逻辑
- `tobacco_core/presets.py`：档位模板和分段定义
